ENGINEERING NOTES

Small surface. Explicit guarantees.

This is a self-initiated portfolio demonstration, built with synthetic data. The CRM is an in-process deterministic simulator.

Idempotency
Event ID + canonical payload fingerprint. Identical submissions reuse the event; conflicting payloads return HTTP 409.
Bounded retries
Three attempts per cycle, with 0.6s and 1.2s backoff. Exhausted events wait in the dead-letter queue.
Recovery
Manual replay clears the simulated outage and requeues the same event while preserving its original payload and audit history.
Persistence
SQLite WAL. Queue state, mock CRM insertion and audit entries commit together. The demo runs in one process.
Scope of the guarantee
One mock CRM record per event inside this local transaction boundary. This is not a claim of exactly-once delivery to an external service.
